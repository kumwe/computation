# Portable consumer example

Run `php examples/typed-consumer.php` after Composer installation. An installed dependency consumer can
pass its own autoloader as the first argument, which is how the built-ZIP consumer gate exercises it.

The example constructs exact contract/capability metadata, checks a compatibility requirement, binds
opaque program bytes to a complete plan identity, derives a deterministic cache key and round-trips an
ordered document batch. All profile/build coordinates are clearly synthetic transport fixtures.

There is no native execution in this example. A real compiler/executor must be supplied only by the
separately released native-binding successor, after the verified baseline/Engine/extension gates.
Use package tests for portable invariants; App retains implementation/composition tests after adoption.
